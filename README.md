# Nkaewam Tap

## How do I install these formulae?

`brew install nkaewam/tap/<formula>`

Or `brew tap nkaewam/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nkaewam/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
